# CookieClicker 🍪

Cookie Clicker est un jeu incrémental où le joueur clique pour produire des cookies et débloque progressivement des
améliorations automatiques.

Le but est d’optimiser sa production pour atteindre des quantités toujours plus massives grâce à une progression
exponentielle. 🍪

## Langages

HTML CSS JavaScript PHP

## Lancer le serveur

Depuis la racine du projet :

```bash
php -S localhost:8000
```

Puis ouvrir http://localhost:8000
Le terminal reste occupé tant que le serveur tourne (`Ctrl+C` pour l'arrêter).
